# 🤖 Desafio DIO — Engenharia de Prompts
## Agente de Atendimento ao Cliente | Banco Digital

### 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio da **DIO (Digital Innovation One)**, com o objetivo de aplicar técnicas de Engenharia de Prompts na criação de um agente de Inteligência Artificial para atendimento ao cliente.

O agente simula um atendente de banco digital, preparado para responder dúvidas de clientes de maneira clara, objetiva, cordial e segura, utilizando instruções bem estruturadas.

### 🎯 Objetivo

Criar um prompt capaz de orientar uma IA a realizar atendimentos eficientes, priorizando a resolução das dúvidas na primeira interação, respeitando a segurança das informações e evitando respostas inventadas.

### 💬 Funcionalidades do agente

O agente foi desenvolvido para auxiliar clientes nas seguintes situações:

- Consultar o valor e a data de vencimento da fatura do cartão.
- Explicar cobranças que o cliente não reconhece.
- Orientar o desbloqueio de um cartão novo.
- Informar o limite disponível e orientar como solicitar aumento.

### 🛡️ Regras de atendimento

O agente deve:

- Utilizar linguagem direta, cordial e profissional.
- Responder de forma objetiva, respeitando o limite de cinco linhas sempre que possível.
- Organizar procedimentos em listas numeradas.
- Nunca solicitar senhas, códigos SMS ou o número completo do cartão.
- Não inventar valores, taxas, prazos ou números de protocolo.
- Encaminhar situações sensíveis para atendimento humano quando necessário.

### 🧠 Conceitos aplicados

- Engenharia de Prompts.
- Definição de persona e contexto.
- Instruções e restrições.
- Organização de respostas.
- Segurança e proteção de dados.
- Direcionamento de comportamento de uma IA.

### 📂 Arquivo do projeto

O repositório contém o prompt desenvolvido para configurar o comportamento do agente de atendimento bancário.

### 🚀 Aprendizado

Este desafio demonstra como a construção de instruções claras, estruturadas e contextualizadas pode contribuir para melhorar a qualidade das respostas de uma Inteligência Artificial, tornando o atendimento mais eficiente, seguro e consistente.
